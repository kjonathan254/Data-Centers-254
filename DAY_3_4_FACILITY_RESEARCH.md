## Data Collection Template

For each facility, collect the following information:

### Basic Information
- [ ] Official facility name
- [ ] Operator/owner company
- [ ] Physical address
- [ ] GPS coordinates
- [ ] Year opened/commissioned
- [ ] Current status (Operational/Under Construction/Planned/Announced)

### Technical Specifications
- [ ] Total floor space (sqm)
- [ ] IT load capacity (MW)
- [ ] Total power capacity (MW)
- [ ] Number of racks/cabinets
- [ ] Rack density options (kW/rack)
- [ ] Tier rating/certification
- [ ] Cooling technology type
- [ ] Power sources (grid/renewable mix)

### Connectivity
- [ ] Fibre providers available
- [ ] Subsea cable connections
- [ ] IXP presence
- [ ] Cloud on-ramps (AWS, Azure, Google, etc.)
- [ ] Cross-connect pricing

### Commercial Information
- [ ] Colocation pricing (per rack/cabinet)
- [ ] Power pricing (per kW)
- [ ] Cross-connect fees
- [ ] Minimum commitment requirements
- [ ] Service level agreements

### Certifications & Compliance
- [ ] ISO 27001
- [ ] ISO 50001
- [ ] Tier certification (Uptime Institute)
- [ ] PCI DSS
- [ ] Local regulatory compliance

### Sustainability
- [ ] PUE rating
- [ ] Renewable energy percentage
- [ ] Carbon neutrality commitments
- [ ] Water usage efficiency

### Tenants
- [ ] Major anchor tenants (if public)
- [ ] Hyperscaler presence
- [ ] Government tenants
- [ ] Financial sector tenants

### Contact Information
- [ ] Sales email
- [ ] Technical contact
- [ ] Media/PR contact
- [ ] Website URL
- [ ] LinkedIn page

## Research Methodology

### Primary Sources (Highest Confidence)
1. **Direct operator engagement** - Email/phone interviews with facility operators
2. **Site visits** - Physical verification where possible
3. **Official documentation** - Operator brochures, datasheets, websites
4. **Industry reports** - Paid research from IDC, Omdia, ResearchAndMarkets

### Secondary Sources (Medium Confidence)
1. **News articles** - Industry publications (Data Centre Dynamics, Capacity Media)
2. **Press releases** - Operator announcements
3. **Conference presentations** - Industry event slides
4. **Government filings** - Regulatory submissions, CAK reports

### Tertiary Sources (Low Confidence - Requires Verification)
1. **Wikipedia** - Community-edited information
2. **Social media** - LinkedIn posts, Twitter announcements
3. **Industry rumors** - Unconfirmed market intelligence
4. **Competitor claims** - Marketing materials from competing operators
